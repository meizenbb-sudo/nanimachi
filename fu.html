符の数え方

点数は「翻」と「符」で決まります。符は手の形とアガリ方から数える細かい点で、数え方を覚えれば点数表の見方がぐっと分かりやすくなります。例はすべてこのアプリの計算で確かめています。

符とは

翻が「役やドラの数」なのに対して、符は「どんな形で、どうアガったか」を表します。同じ1翻でも、30符なら1,000点、40符なら1,300点（子のロン）と点数が変わります。

ただし、満貫（5翻）以上になると符は点数に関係なくなります。符が効いてくるのは4翻までの手です。

数える順番

  1. 副底（フーテイ）20符…どんなアガリにも付く基本の符です。
  2. アガリ方…門前でロンしたら＋10符（門前加符）。ツモでアガったら＋2符（ツモ符。平和のツモは例外で付きません）。
  3. 待ちの形…単騎・カンチャン・ペンチャン待ちは＋2符。リャンメン・シャンポンは0符です。
  4. 雀頭…三元牌（白・發・中）、自風、場風の対子は＋2符。場風と自風が同じ（東場の東家の東など）ときは＋4符と数えるのが一般的です（＋2符のルールもあります）。
  5. 面子…刻子・槓子に符が付きます（下の表）。順子は0符です。
  6. 合計を10符単位に切り上げ…32符なら40符、50符ならそのまま50符です。

刻子・槓子の符

2〜8の数牌1・9・字牌
明刻（ポンした刻子）24
暗刻（自分で集めた刻子）48
明槓（明カン）816
暗槓（暗カン）1632

覚え方は「中張牌の明刻が2符、幺九牌（1・9・字牌）なら2倍、暗刻なら2倍、槓子なら4倍」です。

シャンポン待ちのロンに注意。シャンポン待ちをロンで完成させた刻子は、自分で集めていても明刻として数えます（ツモなら暗刻）。三暗刻や四暗刻が付くかどうかにも関わる、大事な決まりです。

例外の3つ

  • 七対子は25符で固定…ほかの符は数えません。
  • 平和のツモは20符…ツモ符の2符も付けず、20符のまま数えます。
  • 鳴いて20符のままのアガリは30符…鳴いた手で符が副底だけ（すべて順子・リャンメン待ち・役牌でない雀頭）のとき、切り上げても20符ですが、30符として数えます（喰い平和形）。

計算の例

例1 平和のロン → 30符

＋ （ロン）

副底20＋門前ロン10＝30符。順子だけ・リャンメン待ち・雀頭も役牌でないので、ほかに符はありません。平和 1翻30符で1,000点です。

例2 平和のツモ → 20符

＋ （ツモ）

平和のツモは20符。メンゼンツモと平和で2翻20符、子なら400-700（子が400点・親が700点を払う）です。

例3 暗刻・明刻・単騎・ツモ → 34符を40符に

ポン ＋ ＋ （ツモ）

副底20＋ツモ2＋単騎待ち2＋東の暗刻8＋6筒の明刻2＝34符 → 切り上げて40符。東場なら東が場風の役牌なので1翻、40符1翻のツモで子は400-700です。鳴いているので門前ロンの10符は付きません。

例4 三暗刻 → 50符

＋ （ロン）

副底20＋門前ロン10＋1萬の暗刻8＋5筒の暗刻4＋9索の暗刻8＝50符。三暗刻 2翻50符で3,200点です。1萬・9索は幺九牌なので暗刻が8符、5筒は中張牌なので4符です。

例5 槓子が入ると符が大きくなる → 70符

明カン 明カン 暗カン ＋ ＋ （ロン）

副底20＋単騎待ち2＋2筒の明槓8＋7索の明槓8＋9萬の暗槓32＝70符。三槓子 2翻70符で4,500点です。

例6 鳴いた平和形 → 30符

チー ＋ ＋ （ロン）

符は副底の20符だけですが、鳴いているので30符として数えます。タンヤオ 1翻30符で1,000点です。

例7 七対子 → 25符

＋ （ロン）

七対子は25符で固定。2翻25符で1,600点、ツモならメンゼンツモが付いて3翻25符（子は800-1,600）です。

よく出る符の目安

  • 30符…門前ロンで、刻子がなくリャンメン待ちの手。鳴いた手も多くは30符です。いちばんよく出ます。
  • 40符…門前ロンで、暗刻が1つある・単騎やカンチャン・ペンチャン待ち、など（32〜40符が切り上がって40符）。
  • 50符以上…門前ロンで幺九牌の暗刻が2つ以上ある、幺九牌を暗カンしている、など。

符を固定するルール

仲間うちの麻雀では、符を数えずに30符固定や40符固定で点数を出すこともあります。アプリの「ルール設定」の「符」で選べます。そのときも七対子の25符・平和ツモの20符を例外として残すか（最初は残す）を切り替えられます。

アプリでの見え方

「何待ち？」は、アガリ形やテンパイの形を押すと、下から内訳が出ます。役と翻数に加えて、副底・門前ロン・待ち・雀頭・刻子の符を1行ずつ表示するので、「なぜ40符なのか」をそのまま確かめられます。点数の出し方は点数計算のしくみで説明しています。
